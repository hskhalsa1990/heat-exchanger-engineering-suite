# Usage Notes

## Running the executed notebook
The file `notebooks/Heat_Exchanger_Complete_Suite_Executed.ipynb` already contains all cell outputs (text, tables, and embedded plots where captured). Open it directly in Jupyter or VS Code / Cursor.

## Reproducing figures
All high-resolution figures under `figures/` can be regenerated by running the figure-generation script logic present in the notebook cells (or the standalone Python snippet used during packaging).

## PDF Report
`reports/HX_Predictive_Maintenance_Report.pdf` is produced automatically by the final reporting cell. Open it for a management-ready summary of health index, RUL, fleet status and recommended actions.
